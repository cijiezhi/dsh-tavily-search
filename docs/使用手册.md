# 使用手册

> 安装与配置见根目录 [README.md](../README.md) 与 [配置手册](./配置手册.md)。

## 入口在哪

Web GUI **左侧栏**「新会话」下方的图标列里，排在官方「插件」与「写作助手功能」之后
（`order: 30`）。图标是一个放大镜，悬停显示「Tavily 搜索」。

- **点一下**图标 → 主栏切到本插件的面板；
- **再点一下**，或点其它面板图标，或按面板右上关闭 → 切回对话。

## 面板有什么

自上而下五块：

### 1. 开关

| 状态 | 行为 |
|---|---|
| 勾选（默认） | 模型的 `web_search` 走 **Tavily**，消耗 Tavily 额度 |
| 不勾选 | 模型的 `web_search` 走 **DeepSeek 兜底**，**不消耗 Tavily 额度** |

两种状态下搜索都可用。改动**立即生效**，不用重启。

> **开关是总闸**：它同时管三处 —— 模型的 `web_search`、面板的「测试」、面板的「直接搜索」。
> 关闭后：直搜改走 DeepSeek 兜底（结果里标注 `deepseek-fallback`），
> 「测试」则明确返回「已跳过，未消耗额度」。所以关掉开关后**点任何按钮都不会偷烧 Tavily 额度**。

### 2. API Key

- **状态**：显示「已配置（来源：file）」或「未配置」；来源 `file` 表示来自 DSH 凭证库。
- **新 Key**：粘贴后点「保存」。输入框永远显示空白是**正常的** —— Key 会被官方红线处理，
  回读不带出明文，所以占位文字写「已配置（留空表示不改动）」。
- **清除**：从凭证库移除该条目。
- 保存后**下一次搜索即生效**（官方凭证约定：每次操作重新解析）。

### 3. 搜索精度

| 控件 | 默认 | 说明 |
|---|---|---|
| 深度 | `advanced` | `advanced` = 最高精度，**2 credits/次**；其余档 1 credit |
| 条数 | `20` | Tavily 上限 20；seam 与面板直搜都遵守 |
| 摘要 | `advanced` | 模型 `web_search` 的答案摘要档位 |
| 直搜摘要 | `advanced` | 下面「直接搜索」用的档位 |

这些改动**立即生效**（宿主的 provider 每次搜索都重读一次状态文件），不用重启。

> `chunks_per_source`（每条来源片段数）与 `include_usage` 属于 Config 项，面板未暴露，见 [配置手册](./配置手册.md)。

### 4. 连通性与额度

- **测试**：真打一次 Tavily，显示「N 条来源，耗时 X ms，消耗 N credits｜首条 URL」。
- **查额度**：调 Tavily `GET /usage`，显示「本 key 剩余 X/Y credits｜套餐 Z｜本月剩余 A/B」。

额度口径：`advanced` 深度 = **2 credits × 查询数**；其余档 = 1 credit × 查询数。
一次 `web_search` 里模型可能发多个查询词，每个都是一次计费。

### 5. 直接搜索（不经模型）

输入问题 → 点「搜索」（或 `Ctrl/Cmd + Enter`），返回：

- **答案正文**：Tavily 生成的答案摘要（`advanced` 档，最详细）；
- **来源**：标题 + 链接，**不含网页正文片段**；
- **元信息**：耗时、来源条数、本次消耗的 credits。

答案区与来源列表各自**限高可滚**，所以一次搜索不会把面板顶长。

> 直搜固定用「精度拉满」的参数（advanced 深度 + advanced 摘要 + chunks 3），
> 与模型的 `web_search` 互相独立：它消耗额度，但**不经模型上下文**。

## 常见用法

**换 Key**：面板「API Key」粘贴新的 → 保存 → 下一次搜索生效（不用重启）。

**省额度**：把「深度」调到 `basic`（1 credit/次）；或直接关掉开关走 DeepSeek 兜底。

**查一次资料但不让模型看见**：用面板直搜。结果只显示在面板里，不进对话上下文。

**让模型联网检索**：正常提问即可，模型自己调 `web_search`（走 Tavily）；
需要读全文时它自己调 `web_fetch`（走内置 `http` provider）。

## 数据与隐私

| 东西 | 存哪 |
|---|---|
| API Key | DSH 官方凭证库（`~/.dsh/.credentials.yaml` 的 `refs`） |
| 开关与精度 | `$DSH_HOME/dsh-tavily-search/state.json` |
| 配置默认值 | profile 的 `cordis.yml` / `cordis.patch.yml` |

面板与插件都读不到 Key 明文；`state.json` 里只有引用名（如 `TAVILY_API_KEY`）。
搜索内容会按 Tavily 的隐私政策发给 Tavily（直搜与 `web_search` 都是）。
